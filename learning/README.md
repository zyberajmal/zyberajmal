# Knowledge & Lab

My professional portfolio is supported by two public learning spaces: **ZyberKnowledge** for structured technical reference material and **ZyberLab** for hands-on cybersecurity learning and validation.

Together they reflect the way I prefer to develop technical understanding:

> **Learn → Build → Test → Observe → Understand → Document → Improve**

## ZyberKnowledge

**Enterprise Technology & Security Knowledge Base**

ZyberKnowledge is my maintained technical knowledge base for enterprise infrastructure, security engineering, identity, detection and response, governance, and engineering practices.

It contains structured reference material, implementation guidance, detection use cases, troubleshooting procedures and lessons developed through research, professional experience and controlled lab validation.

Key areas include:

- Enterprise infrastructure
- Windows and Active Directory
- Security engineering
- Identity and access management
- Detection and response
- Governance and hardening
- Engineering playbooks
- Technical documentation standards

[Open ZyberKnowledge on GitBook](https://ajmal-anwar.gitbook.io/zyberspace-by-ajmal/zyberknowledge)

## ZyberLab

**Practical Cybersecurity Lab & Hands-On Learning**

ZyberLab is my hands-on cybersecurity learning environment for building, testing, observing and understanding security concepts through small practical exercises.

The lab is intentionally designed to remain clean and easy to maintain. It grows only when a new learning objective requires another system, tool or security control.

Current learning areas include:

- VMware lab setup
- Windows Server
- Active Directory fundamentals
- Windows security events
- Active Directory security monitoring
- Sysmon and endpoint visibility
- Basic networking and troubleshooting
- Security monitoring
- Simple investigation workflows

[Open ZyberLab on GitBook](https://ajmal-anwar.gitbook.io/zyberspace-by-ajmal/)

## How They Connect to the Portfolio

The three areas serve different purposes:

| Area | Purpose |
|---|---|
| **Portfolio** | Shows business problems, project contribution, implementation approach and outcomes |
| **ZyberKnowledge** | Provides deeper technical concepts, engineering context and maintained reference material |
| **ZyberLab** | Provides practical exercises used to build, test and validate technical understanding |

A project case study can therefore remain concise while the deeper technical concepts live in ZyberKnowledge and practical validation can be documented in ZyberLab.

## Publication Approach

The public learning spaces contain generalized technical information intended for professional learning and reference.

Confidential company information, internal architecture, credentials, production identifiers, organization-specific security gaps and other sensitive operational details are excluded from the published material.
