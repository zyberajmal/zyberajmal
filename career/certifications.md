# Professional Certifications

My certifications support the areas I work across today, including cybersecurity architecture, security operations, identity, networking and enterprise security fundamentals.

## Cybersecurity

### Certified Ethical Hacker (CEH)

Provides a structured understanding of common attack techniques, vulnerabilities, security testing concepts and defensive considerations.

### Microsoft SC-100 | Cybersecurity Architect Expert

Focuses on cybersecurity architecture, security strategy, Zero Trust principles, governance, identity, infrastructure and security operations across enterprise environments.

### Microsoft SC-200 | Security Operations Analyst Associate

Focuses on security operations, threat investigation, detection, incident response and the use of security monitoring platforms.

### Microsoft SC-900 | Security, Compliance, and Identity Fundamentals

Covers foundational concepts across security, compliance, identity and Microsoft cloud security services.

## Networking

### Cisco Certified Network Associate (CCNA)

Provides a strong networking foundation across routing, switching, IP connectivity, network services, security fundamentals and enterprise network operations.

## How Certifications Fit My Work

I view certifications as one part of professional development. Their value comes from combining structured learning with practical implementation, troubleshooting, documentation and continued hands-on experience.

My broader goal is to understand how infrastructure, security controls, identity, networking, governance and business operations connect in a real enterprise environment.
